AI access without sharing the master key.

One focused workflow

LiteGate stays between your users and LiteLLM's administrator surface, exposing only the controls each person needs.

01

Sign in

Use your OIDC provider or a locally managed account with rechecked roles and account status.

02

Create a key

Generate a personal virtual key that inherits the configured models, budget, and rate limits.

03

Manage access

Inspect policy and spend, then rotate the credential without resetting accumulated usage.

Run LiteGate yourself

Deploy the prebuilt container with Docker Compose, or build the project locally.

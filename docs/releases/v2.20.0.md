# LiteGate v2.20.0

## Highlights

- **Budget allocation:** Opt-in equal shares of group budgets for participating
  members, with child envelopes, manual overrides and `perUser` ceilings.
- **Safer synchronization:** Collect current spend before allocating and verify
  decreases before increases. First-time provisioning and deficit resets use
  current spend floors without altering snapshots already in use.
- **Accounting safeguards:** Reject unsafe multi-key migration, incomplete source
  metadata and unresolved managed-group transfers before raising allowances.

## Upgrade Notes

- Enforcement defaults **off**. Enable `HIERARCHICAL_BUDGETS_ENFORCED`, Docker
  `hierarchical_budgets_enforced`, or Helm `config.hierarchicalBudgetsEnforced`.
- Enforced managed accounts support one key. Additional keys, overlapping
  rotation, deletion and manual spend resets are blocked to preserve accounting.
  Managed transfers require operator review before source capacity is released.
- Limits remain eventual per-key caps with separate reset periods, **not strict
  atomic group limits**. External changes and lost process history need review.
  Removed-group cleanup still assesses and audits; it does not delete teams.
- Keep the SQLite database on persistent storage and back it up before upgrading.

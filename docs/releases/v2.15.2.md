# LiteGate v2.15.2

## Highlights

- **Hierarchy files:** UTF-8 JSON `{"levels": [...]}` via `organization_hierarchy_file` / `ORGANIZATION_HIERARCHY_FILE`; relative paths resolve against `backend/`. Existing validation, identity matching and budgets apply.
- **Helm:** `organizationHierarchyFile` mounts an existing namespace ConfigMap read-only using subPath; defaults are key `organization.json` and path `/etc/litegate/organization.json`.
- **Compose:** Optional read-only JSON mounts.

## Upgrade Notes

- File input defaults off; inline YAML/environment JSON remain supported. Nonempty inline levels cannot coexist with a file; missing/unreadable/malformed/invalid files fail startup.
- Files load at startup. Helm file-option changes roll out; external ConfigMap content changes need an explicit rollout restart.
- This does not restore the removed standalone email-mapping schema or alter authentication, verification, identity bindings or budgets.

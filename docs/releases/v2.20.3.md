# LiteGate v2.20.3

## Highlights

- **Self-service key replacement with enforced budgets:** Members can use
  **Regenerate key** again, including after moving to another group or a restart
  without persistent storage. The old key is paused for about 12 seconds while
  its spend is recorded, so the new key carries the full spend. If anything
  fails, the old key is kept and keeps working.
- **Moved members no longer block everyone:** A member moved to another group
  with an existing key could not sign in, and budget updates stopped for all
  members. Their key and spend now move to the new group automatically.

## Upgrade Notes

- After a restart that lost the database, members sign in again before
  replacing their key. Applications using the old key must switch to the new one.
- No new dependencies, database migrations or configuration settings.

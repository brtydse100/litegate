# LiteGate v2.22.0

## Highlights

- **Apple-style redesign:** The portal follows Apple's Human Interface
  Guidelines, with the system font, one blue accent, a light sidebar, large
  page titles and flatter grouped sections in light and dark themes. LiteGate
  has a new default mark.
- **Several departments at once:** The Organization page combines any set of
  departments, or **All**, across its cards, group table and usage report.
- **Compact usage report:** Small spend, request, token and model charts show
  exact values on hover, tap or arrow keys, and the report can be closed.
- **Team owners split budgets in place:** Owners get the Organization view for
  their teams and edit member allowances directly in a People list.
- **Faster finding:** A breadcrumb shows the open group's path, and Keys
  filter by All, Active or Blocked.

## Upgrade Notes

- `GET /api/v1/organization/users` and `/usage` accept a repeated `node`
  parameter (up to 50 groups); usage `by_group` entries add a `daily` array.
  Both changes are additive.
- The default sign-in and sidebar mark changed. A configured `logo_url` is
  unaffected.
- No new settings, dependencies or database migrations.

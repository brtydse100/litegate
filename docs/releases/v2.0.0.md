## What's Changed

LiteGate 2.0 turns the self-hosted key portal into a lightweight access and
automation layer for LiteLLM.

- Added persistent local users with `user` and `admin` roles, password resets,
  and account enable/disable controls.
- Added generic OpenID Connect login with administrator assignment by email or
  SSO group.
- Added the stable `/api/v1` management API and optional `management_api_key`.
- Added administrator-only bulk editing for key models, budgets, rate limits,
  duration, aliases, and blocked state.
- Replaced expensive dashboard spend-log downloads with compact key data and
  paginated installation-wide key loading.
- Added Docker Compose, Helm, health, OpenAPI, Swagger UI, and ReDoc support.

### Access and security

Normal users can manage only their personal key. Bulk key and local-user
administration require an administrator portal session or the installation-wide
management API key. OIDC tokens are verified, local passwords are hashed, and
key-changing operations are rate-limited.

### Upgrade

Preserve the configured local-user database path or Docker volume when replacing
a container. LiteGate creates the SQLite schema automatically; no manual schema
migration is required. Replace the sample master key, JWT secret, and bootstrap
administrator password before deployment.

See the [configuration guide](../configuration.md), [API guide](../../API.md),
and [deployment guide](../../DEPLOYMENT.md) for setup details.

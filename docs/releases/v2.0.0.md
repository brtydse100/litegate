# LiteGate v2.0.0

## Highlights

- **Accounts:** Persistent local users, password resets and user/admin roles; verified OIDC sign-in with email/group administrator assignment.
- **Administration:** Stable `/api/v1` API, optional management credential and bulk key policy editing.
- **Operations:** Lightweight dashboard metadata, paginated keys, Docker Compose, Helm, health checks and API documentation.

## Upgrade Notes

- Preserve the SQLite path/volume; schema creation is automatic.
- Replace sample master keys, JWT secrets and bootstrap credentials before deployment.
- Ordinary users access only their own key. User and bulk-key administration require an administrator session or management credential; passwords are hashed and key mutations rate-limited.

# LiteGate v2.4.0

## Highlights

- **Rotation:** Preserve accumulated key spend so replacing a secret cannot reset its allowance.
- **Cooldowns:** Disable key, account, team and bulk mutations while displaying the remaining wait.
- **Container security:** Run as UID/GID `10001:10001` on port `8080`; Helm drops capabilities, prevents privilege escalation and uses runtime-default seccomp with `fsGroup` storage ownership.

## Upgrade Notes

- New volumes need no preparation. For root-owned volumes from 2.3 or older, run once from `deploy/docker-compose`:

```bash
docker compose -f docker-compose.image.yml run --rm --user 0 \
  --entrypoint chown litegate -R 10001:10001 /app/backend/data
docker compose -f docker-compose.image.yml up -d
```

- Kubernetes uses `fsGroup: 10001`. Use LiteLLM user/team budgets for ceilings shared across multiple credentials or keys created outside LiteGate.

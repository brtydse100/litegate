# LiteGate 2.7.0

## What's Changed

- Dashboard users can view the models available to their LiteLLM key.
- Administrators can reset spend for selected keys.
- Local-user navigation is configurable, and non-administrators no longer see
  the administrator sidebar.

## Upgrade

```bash
docker pull ghcr.io/brtydse100/litegate:2.7.0
```

No configuration or storage migration is required from 2.6.1.

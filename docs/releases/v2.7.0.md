# LiteGate v2.7.0

## Highlights

- **Models:** Dashboard users can inspect accessible models.
- **Keys:** Administrators can reset selected-key spend; stale manual key-ID entry is removed.
- **Navigation:** Configurable local-user navigation; ordinary users no longer see the administrator sidebar.
- **Compatibility:** Preserve the single-key spend-reset payload and run the interactive demo in CI.

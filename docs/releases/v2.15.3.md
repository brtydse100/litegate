## What's Changed

- Fix small spend charts and preserve counters during key regeneration by @brtydse100 in [#42](https://github.com/brtydse100/litegate/pull/42)

### Spend charts and current counters

Hierarchy spend charts retain up to six decimal places and use scientific
notation below a microdollar. Usage bars scale to the selected maximum, and
longer axis labels fit inside the chart.

The personal dashboard reads live owned-key counters rather than potentially
stale user-list spend. Regeneration verifies carried spend after budget-policy
updates and before deleting original keys. If the replacement cannot be
verified, it is revoked and the original alias restored. Counter decreases
require valid advancing reset timestamps; unavailable counters return an error
instead of becoming zero.

### Upgrade and limits

No configuration changes or migration are required. Historical charts and
current budget counters can cover different periods. This release does not
reconstruct counters already reset to zero from historical usage, and cannot
serialize independent LiteLLM requests or spend flushes.

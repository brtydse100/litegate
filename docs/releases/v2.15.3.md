# LiteGate v2.15.3

## Highlights

- **Charts:** Six-decimal small-spend labels, scientific notation below a microdollar, bars scaled to the selected maximum and fitting axis labels.
- **Counters:** Personal dashboards read live owned-key spend rather than stale user-list totals.
- **Rotation:** Verify carried spend after policy updates and before revoking originals. Failed verification revokes the replacement and restores the old alias; counter decreases need valid advancing reset timestamps. Missing counters produce errors, not zero.

# LiteGate v2.17.0

## Highlights

- **Appearance:** Independent multiline `login_text`/`my_key_text` guidance and shared `logo_url`; HTML/Markdown display literally. Empty login text retains the subtitle; empty My key text hides guidance.
- **Key actions:** Hide API key replaces regeneration while a one-time secret is visible; hiding restores regeneration with existing cooldowns. Copy/reveal and spend-preserving rotation remain supported.
- **Deployment:** Docker/Compose hierarchy examples cover YAML, JSON, mounts, precedence and restarts; allowances remain distinct from rate/concurrency limits.
- **CI fix:** Correct the truncated Nightly E2E Node action SHA; schedule, Node version, permissions and browser suite are unchanged.

## Upgrade Notes

- Configure YAML, `LOGIN_TEXT`/`MY_KEY_TEXT`/`LOGO_URL`, or Helm `config.loginText`/`config.myKeyText`/`config.logoUrl`; environment overrides YAML.
- Restart/recreate the backend after changes, including Helm appearance upgrades. Runtime text/URLs need no frontend rebuild; bundled assets need a build or static mount.
- Appearance endpoints are public: use content suitable for unauthenticated visitors. Authentication, key policy and secret-storage defaults are unchanged.

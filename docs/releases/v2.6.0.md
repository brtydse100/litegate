# LiteGate v2.6.0

## Highlights

- **Portal:** Responsive key, budget, model, expiry, team and rate summaries; complete administrator workflows and persisted light/dark themes.
- **Demo:** The real frontend runs on synthetic browser-local data with administrator/user switching; unsupported SSO is hidden.
- **Compatibility:** Live LiteLLM fixes avoid unrevealed provisioning keys and normalize nested team-update responses.
- **Delivery:** Digest-pinned LiteLLM/PostgreSQL integration tests, expanded PR checks and nightly full browser tests; sharper, smaller documentation media.

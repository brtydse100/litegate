# LiteGate v2.12.2

## Highlights

- **Verification:** Optional outgoing TLS and generic OAuth email-verification controls, both defaulting to true.
- **Helm validation:** A nonempty `customCA` requires exactly one namespace-local ConfigMap or Secret; key/path-only definitions fail rendering.

## Upgrade Notes

- No database migration from 2.12.1; upgrade chart and image together and restart the Deployment after verification changes.
- `config.sslVerify: false` removes server identity checks for outgoing LiteLLM/SSO HTTPS. Prefer `customCA` for private CAs; `mountPath` is an in-pod destination.
- `config.genericRequireVerifiedEmail: false` accepts explicitly unverified generic OAuth emails, including email-based admin matching. Use trusted provider-controlled emails/groups. Missing verification/email claims retain existing behavior; OIDC is unchanged.

## What's Changed

- Add Helm verification options and validate custom CA sources by @brtydse100 in [#23](https://github.com/brtydse100/litegate/pull/23)

### Configuration and upgrade notes

- No database migration is required from 2.12.1. Both new verification options
  default to `true`, preserving existing authentication and TLS behavior.
- Set `config.sslVerify: false` to skip server certificate verification for
  outgoing LiteLLM and SSO HTTPS requests. Prefer `customCA` for private CAs;
  disabling verification removes server identity checks.
- Set `config.genericRequireVerifiedEmail: false` to allow generic OAuth login
  when UserInfo explicitly reports `email_verified: false`. Missing email or
  verification claims remain accepted, and OIDC email handling is unchanged.
  Allowing unverified email also allows email-based administrator matching;
  use provider-controlled email attributes or trusted administrator groups.
- A nonempty `customCA` must specify exactly one existing `configMap` or `secret`
  in the LiteGate namespace. `mountPath` is the destination inside the pod, not
  a local certificate file. Configuring only `key` or `mountPath` now fails
  Helm rendering instead of silently creating no mount.
- Restart the LiteGate Deployment after applying the verification settings so
  the pod receives the updated ConfigMap environment variables. Update both
  the application image and chart to use the new options.

See the [Helm deployment guide](../../DEPLOYMENT.md#custom-cas-and-additional-resources)
and [configuration reference](../configuration.md).

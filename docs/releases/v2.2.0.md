# LiteGate 2.2.0

LiteGate 2.2.0 adds safe team administration directly to the lightweight portal
and automation API.

## Highlights

- Open the administrator-only **Teams** tab to search and page through teams.
- Create a team with a name, optional stable ID, model allowlist, budget/reset
  policy, TPM/RPM limits, and blocked state.
- Edit a team's policy in a few clicks without exposing the LiteLLM master key to
  the browser.
- Delete an unreferenced team only after typing its exact ID.
- Use equivalent administrator-only routes under `/api/v1/teams` for automation.

## Safety and access

Normal users cannot see the Teams tab or call team-management endpoints. A
trusted agent may use LiteGate's installation-wide `management_api_key`, which
has administrator access and must be protected like a password.

LiteLLM deletes team-scoped API keys when a team is deleted. LiteGate therefore
shows a destructive-action warning, requires exact-ID confirmation in the
portal, and refuses deletion while a team is referenced by
`oidc_group_team_mapping` or `KEY_TEAM_ID`.

## Upgrade

Pull `ghcr.io/brtydse100/litegate:2.2.0`, update the Helm chart, or rebuild from
source. No LiteGate database migration or new configuration value is required.
The Teams page uses LiteLLM's paginated `/v2/team/list` management endpoint, so
the connected LiteLLM deployment must provide that route.

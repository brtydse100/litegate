## What's Changed

LiteGate 2.3 adds safe, administrator-controlled movement of users between
LiteLLM teams.

- Added a **Members** view for each team.
- Added a few-click user move flow with destination search and explicit policy
  confirmation.
- Added `POST /api/v1/teams/{source_team_id}/members/move` for automation.
- Preserved the member's LiteLLM role and moved every key scoped to the source
  team.

### Safety

LiteLLM member removal can delete the member's team-scoped keys. LiteGate first
adds the destination membership, then moves and verifies the keys, and only then
removes the source membership. A failed migration keeps the source membership.

Moves support up to 500 source-team keys and are blocked for teams referenced by
`oidc_group_team_mapping` or `KEY_TEAM_ID` until configuration is changed.
Normal users cannot view team members or move them.

### Upgrade

No LiteGate database migration or new required setting is introduced. See
[team management](../features.md#administrator-only-team-management) for the full move
behavior.

# LiteGate v2.21.0

## Highlights

- **Redesigned portal:** My key shows what is left to spend, when it refills
  and whether you are on track. Every page shares one design in light and dark
  themes, from phones to wide screens, with better keyboard and screen-reader
  support.
- **Far fewer LiteLLM requests for large organizations:** The Organization
  page reads two shared listings instead of one request per group or member,
  and budget updates lock only the groups they affect.
- **Per-user limits in the portal:** System administrators can override a
  group's configured per-user limit and restore it later.
- **Your own setup guide:** An optional link on My key points people to your
  instructions for using their key.
- **Reliable SSO sign-in:** ID tokens tolerate 10 seconds of clock skew.

## Upgrade Notes

- The organization sweep runs every 15 minutes by default
  (`ORGANIZATION_SYNC_INTERVAL_SECONDS`, 60 to 86400). Budget edits still apply
  within about a minute. Raised caps after a period reset, newly listed users and
  changes made directly in LiteLLM wait for the next sweep.
- New optional settings: `SETUP_GUIDE_URL` (blank hides the link) and
  `KEY_ROTATION_SETTLE_SECONDS` (default 12). The **Setup guide** link no longer
  opens the API reference; administrators find it in their account menu.
- No new dependencies or database migrations.

# LiteGate v2.11.0

## Highlights

- **Saved keys:** Optional SQLite storage and authorized owner/admin reveal, with live ownership checks, CSRF protection, no-store responses and secret-free auditing.
- **Rotation:** Preserve a working replacement after SQLite cleanup failures; revoked stored keys cannot be revealed.
- **SSO:** Manual authorization/token/JWKS endpoints (all three required), default teams and opt-in full `proxy_admin` inheritance. Scoped/read-only admins are not promoted; default teams do not bypass required mapping.
- **Helm:** Custom CAs, templated resources/OpenShift Routes and restored legacy configuration compatibility.
- **Publication:** Verify multi-architecture pull/save/load before creating releases; official tags match VERSION on main, manual images use test-/dev-, shared aliases promote only from current main.

## Upgrade Notes

- No manual database migration from 2.10.0; the storage table initializes automatically.
- Storage defaults off. Enable `save_api_keys_in_db`, `SAVE_API_KEYS_IN_DB` or Helm `config.saveApiKeysInDb` explicitly.
- **Saved keys are plaintext credentials. Protect the database, volume and backups.** Disabling storage prevents saving/reveal but retains copies.
- Older/external keys need one regeneration before reveal; reveal does not rotate or reset spend. OIDC issuer/signature/state/nonce verification remains enabled.

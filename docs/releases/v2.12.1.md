## Upgrade Notes

- No database migration from 2.12.0.
- Keep bundled values intact; pass overrides with `--values`. Omitted settings use defaults; lists replace the default list.
- To disable bootstrap administration, explicitly empty both `config.localAuthUsername` and `config.localAuthPassword`; removing overrides restores bundled credentials.
- Avoid `--reuse-values` when removed overrides should return to defaults.

### Upgrade notes

- No database migration is required from 2.12.0. Chart templates and application behavior are unchanged.
- Keep the bundled chart values intact and pass your custom overrides with `--values`. Omitted settings use chart defaults; lists replace the default list.
- When disabling the bootstrap administrator for SSO, explicitly set both `config.localAuthUsername` and `config.localAuthPassword` to empty strings. Removing them retains the chart's bootstrap credentials.
- Avoid `--reuse-values` when removed overrides should return to chart defaults.

See the [Helm deployment guide](../../DEPLOYMENT.md#step-2--install).

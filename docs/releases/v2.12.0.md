# LiteGate v2.12.0

## Highlights

- **Generic OAuth:** Authorization/token/UserInfo endpoints, opaque access tokens, configurable ID/email fields, scopes, S256 PKCE and body/HTTP Basic client authentication.
- **Configuration:** Compose YAML, Helm `config:` and optional `GENERIC_*` overrides; historical release-note standardization.
- **Security:** Signed browser state, HttpOnly sessions and existing admin/team rules remain enforced. UserInfo roles cannot grant admin access; incomplete/conflicting providers fail startup.
- **Validation:** Backend/Helm regressions, credential encoding, live LiteLLM and container checks; independent implementation review passed.

## Upgrade Notes

- No database migration from 2.11.0; OIDC/local settings remain compatible.
- For generic SSO, clear OIDC issuer/manual endpoints and configure both client credentials plus all three generic endpoints. Register `/api/auth/callback`; `generic_redirect_uri` overrides the `root_url`-based default.
- Keep a stable UserInfo identity field (default `sub`); changing it or the OAuth client can create separate users.
- Entra UserInfo lacks groups/custom claims: use OIDC for verified group claims. Generic mode does not implement custom handlers, static state, custom headers, token-claim merging or role mappings.

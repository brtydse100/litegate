# LiteGate v2.1.0

## Highlights

- **SSO teams:** Case-insensitive group mapping supports flat/dotted claims and one or several existing LiteLLM team IDs.
- **Memberships:** Sign-in adds missing memberships without removing manually managed ones; optional fail-closed matching rejects unmapped users.
- **Keys:** The first configured match supplies the primary team for new or regenerated keys.

## Upgrade Notes

- Configure `oidc_groups_claim`, `oidc_group_team_mapping` (or JSON `OIDC_GROUP_TEAM_MAPPING`) and optional `oidc_require_team_mapping`.
- Mapping targets are existing team IDs, not aliases. Each key belongs to one team even when the user joins several.
- Existing keys are unchanged: regenerate them or update `team_id` as an administrator.

**Details:** [SSO team mapping](../authentication.md#mapping-sso-groups-to-litellm-teams).

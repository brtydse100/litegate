## What's Changed

- Added configurable audit-event retention with bounded cleanup batches by
  @brtydse100 in [#12](https://github.com/brtydse100/litegate/pull/12).
- Prevented public readiness responses from exposing the configured LiteLLM
  target, by @brtydse100 in [#11](https://github.com/brtydse100/litegate/pull/11).

### Upgrade

Set `audit_retention_days` (or `AUDIT_RETENTION_DAYS`) to control how long
audit events remain in SQLite. The default is 90 days. No storage migration is
required from 2.8.0.

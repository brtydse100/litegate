# LiteGate 2.9.0

## What's Changed

- Added configurable audit-event retention with bounded cleanup batches.
- Prevented public readiness responses from exposing the configured LiteLLM
  target.

## Upgrade

```bash
docker pull ghcr.io/brtydse100/litegate:2.9.0
```

Set `audit_retention_days` (or `AUDIT_RETENTION_DAYS`) to control how long
audit events remain in SQLite. The default is 90 days. No storage migration is
required from 2.8.0.

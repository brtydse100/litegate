# LiteGate v2.18.0

## Highlights

- **Model budgets:** Administrator per-model amounts/reset periods within the key allowance; both limits count independently. Replace/clear the entire mapping explicitly. LiteLLM owns accounting, resets and enforcement.
- **Advanced policies:** Discover administrator key/team fields from LiteLLM OpenAPI with typed/JSON controls, explicit edits and target-change draft resets. Familiar controls work without discovery. Validation excludes secrets, identity bindings, spend and unsupported constraints; existing Enterprise/hierarchy safeguards remain.
- **Compatibility:** Preserve metadata/member allowances during unrelated MCP team updates. Pinned LiteLLM 1.98 supports MCP and member allowance defaults, not per-model team-member budgets.
- **Performance:** Lazy organization branches and selected users/usage reports, cached revisits, independent loading/errors and separate team/subtree spend; one-scrollbar policy editing with cached selection lookups.

## Upgrade Notes

- Pin `2.18.0` and restart. Source installs must update backend requirements for `jsonschema`.
- Model budgets default off. Activate an upstream Enterprise license, then enable `LITELLM_ENTERPRISE_ENABLED`, YAML `litellm_enterprise_enabled` or Helm `config.litellmEnterpriseEnabled`; restart. This is a manual switch, not license detection. Disabling hides/rejects new writes without removing upstream limits.
- **Model budgets must be positive:** LiteLLM treats zero as unlimited. Use model restrictions to deny access.
- Keys with model budgets require administrator-assisted rotation, even with the feature switch off, to preserve usage windows.
- Validation included live pinned LiteLLM and simulated Enterprise enforcement; genuine license verification and external MCP invocation were not tested.

## What's Changed

- Published a conventional multi-platform container index that works with
  standard Docker pull, save, and load workflows without requiring Skopeo, by
  @brtydse100 in [#13](https://github.com/brtydse100/litegate/pull/13).
- Added a release check that exercises the image save/load round trip.
- Added Helm `extraVolumes` and `extraVolumeMounts` settings for externally
  managed storage, including custom mounts at `/app/backend/data`.
- Made the sign-in page retry temporary authentication-configuration failures
  and show a recovery action instead of silently hiding the SSO button.
- Added regression coverage for legacy YAML OIDC configuration.

### Upgrade

No database migration is required from 2.9.0. Existing Helm persistence values
continue to work unchanged. Operators using an external claim can disable the
built-in claim and configure matching `extraVolumes` and `extraVolumeMounts`;
see the [deployment guide](../../DEPLOYMENT.md#local-users-and-persistence).

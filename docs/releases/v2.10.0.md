# LiteGate v2.10.0

## Highlights

- **Images:** Conventional multi-platform indexes support Docker pull/save/load without Skopeo, with a save/load release check.
- **Helm:** `extraVolumes` and `extraVolumeMounts` support external storage, including `/app/backend/data`.
- **Sign-in:** Retry temporary authentication-configuration failures and offer recovery instead of silently hiding SSO.
- **Compatibility:** Regression coverage for legacy YAML OIDC settings.

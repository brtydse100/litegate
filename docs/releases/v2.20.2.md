# LiteGate v2.20.2

## Highlights

- **Clear key status after restarts:** When LiteGate restarts without persistent
  storage, the key page shows one info notice to sign in again instead of
  "mapping was removed" and "Policy unavailable" warnings. Moved users see where
  they were moved; real problems still warn, once.
- **No dead-end regeneration:** With enforced organization budgets, the key page
  no longer offers **Regenerate key** for a managed key the backend would reject,
  and explains that the existing key keeps working.
- **Dismissible notices:** Notifications and error banners close with an **×**.
  Dark-mode hover highlights stay readable.
- **Verified budget authority:** Real Keycloak and LiteLLM browser tests confirm
  team administrators redistribute within their team's total but cannot change
  it, over-allocate it or raise their own share.

## Upgrade Notes

- Keep LiteGate's database on persistent storage (Helm `persistence.enabled`,
  Docker volume). Without it, a restart loses saved key copies and budget
  allocations; users must sign in again to restore organization details.
- No new dependencies, database migrations or configuration settings.

**Details:** [testing enforced budgets with real SSO](../testing-sso.md).

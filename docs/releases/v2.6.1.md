# LiteGate 2.6.1

LiteGate 2.6.1 improves the action hierarchy introduced in 2.6.0 so users can
identify key regeneration and support controls more quickly.

## Highlights

- Key regeneration is now a prominent full-width primary action with a larger
  touch target on desktop and mobile.
- Model-hub and support links use consistent full-width action styling and
  clearer visual contrast.
- Screenshots, SVG source, and the demonstration video now reflect the updated
  portal layout.

## Upgrade

```bash
docker pull ghcr.io/brtydse100/litegate:2.6.1
```

No configuration or storage migration is required from 2.6.0. The container
continues to run as UID/GID `10001:10001`.

See the [deployment guide](../../DEPLOYMENT.md) for Docker Compose and Helm
upgrade instructions.

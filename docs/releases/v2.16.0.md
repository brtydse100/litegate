## What's Changed

- Fix configured Model Hub URL being modified by @brtydse100 in [#44](https://github.com/brtydse100/litegate/pull/44)
- Add configurable parallel request defaults for generated keys by @brtydse100 in [#45](https://github.com/brtydse100/litegate/pull/45)

### Model Hub link upgrade

`litellm_ui_url` is now used exactly as configured. LiteGate no longer appends
`/ui/model_hub_table`. If your configuration supplies only a base URL, update it
to the desired full destination, such as `https://litellm.example.com/ui/model_hub`.
An empty value still hides the button. Helm uses `config.litellmUiUrl`.

### Optional key concurrency default

Set a positive integer with `key_max_parallel_requests` in YAML,
`KEY_MAX_PARALLEL_REQUESTS` in the environment, or `config.keyMaxParallelRequests`
in Helm. LiteGate forwards it to LiteLLM for newly created and regenerated keys,
including organization-managed keys. Omit it to preserve LiteLLM's default.
Existing keys are unchanged until regenerated; LiteLLM enforces the per-key limit.
No new dependencies, services, or persistent state are required.

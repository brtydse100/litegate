# LiteGate v2.16.0

## Highlights

- **Model Hub:** Use `litellm_ui_url` exactly as configured; no appended `/ui/model_hub_table`. Empty values hide the button.
- **Concurrency:** Optional positive `key_max_parallel_requests`, `KEY_MAX_PARALLEL_REQUESTS` or Helm `config.keyMaxParallelRequests` forwards a default for new/regenerated keys, including managed keys.

## Upgrade Notes

- Replace base-only Model Hub URLs with the full destination; Helm uses `config.litellmUiUrl`.
- Omit the concurrency setting to retain LiteLLM defaults. Existing keys change only on regeneration; LiteLLM enforces limits. No new dependencies, services or state.

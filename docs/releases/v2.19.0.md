# LiteGate v2.19.0

## Highlights

- **Personal analytics:** Hourly persisted request, token, cost, model and daily
  snapshots for every portal user, with owner isolation, coverage and freshness.
  Spend displays retain up to ten decimal places for small prompt costs.
- **Organization access:** License-independent scoped delegation requires both
  designation and group administration. A read-only People directory includes
  SSO/no-key identities; full email addresses wrap and copy throughout the UI.
- **Reliability:** Transactional, versioned SQLite initialization preserves
  existing records. Existing-user hierarchy migration retains key identity,
  credentials, spend and restrictions; account switching clears private caches.
- **Policy editing:** Advanced settings retain strict validation with actionable
  field errors. Budget proposals support child reservations, persistent manual
  overrides and equal automatic allocations; activation remains unavailable.
- **Operations:** Opt-in removed-group assessment records safe review outcomes.
  Real Keycloak SSO fixtures and CI cover group changes and account isolation.

## Upgrade Notes

- Preserve the SQLite volume/path, including SSO-only deployments. Back up before
  moving data; enabling persistence does not copy an old ephemeral database.
- Permanent key deletion is administrator-only; owners use spend-preserving
  rotation. Bootstrap usernames are reserved case-insensitively.
- Analytics defaults on with 90-day retention. Budget proposals and retirement
  assessment default off. Proposals do not enforce inference limits; assessment
  does not delete teams. Existing upstream limits remain active.

# LiteGate v2.22.1

## Highlights

- **Separate Audit log page:** Administrators open recent activity at
  **Audit log**, while **Status** shows only dependency readiness. Older
  `/status#audit` links open the new page.
- **Current screenshots:** The README and demo media show the v2.22.0 design.

# LiteGate release notes

Release notes focus on user-visible changes, upgrade requirements, and important
behavior. For an exhaustive history, see the [changelog](../../CHANGELOG.md).

| Version | Main change |
| --- | --- |
| [2.5.0](v2.5.0.md) | Hardened sessions, behavior-first testing, observability, and recovery tooling |
| [2.4.0](v2.4.0.md) | Spend-preserving key rotation, operation cooldowns, and a non-root image |
| [2.3.0](v2.3.0.md) | Safe movement of users and scoped keys between teams |
| [2.2.0](v2.2.0.md) | Administrator team creation, editing, and guarded deletion |
| [2.1.0](v2.1.0.md) | SSO group mapping to LiteLLM teams |
| [2.0.0](v2.0.0.md) | Local users, OIDC, API v1, and administrator bulk key editing |

Container images are published at `ghcr.io/brtydse100/litegate`. Pin a version
tag in production instead of relying on `latest`.

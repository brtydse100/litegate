# LiteGate v2.14.0

## Highlights

- **Migration:** Move existing owned keys in place to the primary mapped/default SSO team or deepest hierarchy team, preserving secrets and spend. Retain old memberships/spend for review.
- **Safety:** Verify inherited allowances and ancestor restrictions; failures retry, with a 500-key per-user bound. Policy-verification errors still require attention.
- **Presentation:** Leaf-group member usage, six-decimal personal spend and stable `name's key` aliases. Rotation temporarily frees conflicting aliases while the old key remains live until generation succeeds; saved-key reveal is unchanged.

# LiteGate v2.20.1

## Highlights

- **Readable costs:** Currency displays use exactly two decimal places across
  key spend, personal analytics, organization charts and allocation summaries.
  Stored amounts, chart proportions and precise numeric editing are preserved.
- **Clear budget authority:** Delegated team totals are visibly read-only;
  child-team controls are labeled as allocations. Backend denial messages and
  direct API regressions reinforce the existing permission boundary.

## Upgrade Notes

- Sub-cent costs round to `$0.00` on screen. This changes presentation only;
  calculations, stored values and precise edit payloads retain their precision.
- Team administrators redistribute the existing assigned allowance among members
  and child teams. Only a parent or system administrator assigns that team's total.
- No new dependencies, database migrations or configuration settings.

**Details:** [currency display and budget authority](../governance-and-analytics.md#budget-planning-and-current-enforcement-boundary).

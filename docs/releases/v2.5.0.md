# LiteGate v2.5.0

## Highlights

- **Sessions:** HttpOnly cookies with origin checks replace browser-readable tokens; OIDC verifies browser-bound state and nonce.
- **Keys:** Spend-preserving regeneration and administrator search/selection across every matching key; personal dashboards stay lightweight.
- **Operations:** Request IDs, structured secret-free logs, authenticated Prometheus metrics, readiness and verified SQLite backup/restore.
- **Validation:** CI covers HTTP contracts, browser workflows, dependency audits, Helm and non-root containers.

# LiteGate demo media

These screenshots are captured from the real LiteGate interface running in demo
mode with sanitized demo data. Each PNG is 2400 x 1350. API keys are masked and
no production credentials or data are shown. For an interactive walkthrough,
open the [live demo](https://brtydse100.github.io/litegate/).

- [`litegate-my-key-hd.png`](./litegate-my-key-hd.png) - the normal user's key
  page, with budget, refill date, team and key actions. Also the README hero.
- [`litegate-my-key-dark-hd.png`](./litegate-my-key-dark-hd.png) - the same page
  in the dark theme.
- [`litegate-regenerate-confirmation-hd.png`](./litegate-regenerate-confirmation-hd.png)
  - explicit confirmation before replacing a key.
- [`litegate-login-hd.png`](./litegate-login-hd.png) - sign-in.
- [`litegate-organization-hd.png`](./litegate-organization-hd.png) - the
  administrator's Organization page with a group open for editing.

# LiteGate demo media

These lossless UI states are rendered from the real LiteGate components with
sanitized demo data. The PNG exports are 2400 x 1350 and the walkthrough is a
1920 x 1080 H.264 video. API keys are masked and no production credentials or
data are shown.

- [`litegate-self-service-demo-hd.mp4`](./litegate-self-service-demo-hd.mp4) -
  sign in, review the assigned key policy, and open the regeneration
  confirmation.
- [`litegate-login-hd.png`](./litegate-login-hd.png) - SSO and local sign-in.
- [`litegate-my-key-hd.png`](./litegate-my-key-hd.png) - the normal user's key
  page.
- [`litegate-regenerate-confirmation-hd.png`](./litegate-regenerate-confirmation-hd.png)
  - explicit confirmation before replacing a key.

The matching SVG files are the lossless sources for the three UI states.
